# ScanLite — Offline QR Scanner

A fast, privacy-first QR and barcode scanner for Android. Fully offline. No internet required.

## Features

- Scan QR codes and barcodes using your device camera
- Scan QR codes from gallery images
- Copy, share, and open scanned content
- URL detection with safe preview
- WiFi network info display
- Phone number and email detection
- Local scan history with search
- Dark / Light / System theme
- Flashlight control
- No internet required — works in airplane mode
- No ads, no tracking, no cloud

## Supported Formats

- QR Code
- EAN-13, EAN-8
- Code 128, Code 39
- UPC-A, UPC-E

## Tech Stack

- Flutter 3.47
- Dart
- Material 3
- mobile_scanner
- shared_preferences

## Privacy

ScanLite processes all QR codes on your device. Scan history is stored locally and is **never** uploaded to any server.
